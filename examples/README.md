# Examples

A read-only, finished sample so you can see what a worked VibeOS project looks like — not an empty template. Nothing here is real; it's a made-up "plan a weekend trip" project used purely to illustrate. Don't edit these files; start your own work with `/new-vibeos-project`.

- [`sample-project/`](sample-project/) — a tiny completed project with a filled context file, a few real-looking memory entries, a distilled set of principles, and a sample teammate output.
