# Sample project — Weekend Trip Plan

> Read-only example. This is a finished, fictional project so newcomers can see what "done" looks like. Don't edit it — make your own with `/new-vibeos-project`.

This little project used the three starter teammates to plan a simple two-day trip:

- **Ada** framed the fuzzy "I want to plan a weekend" into a clear, small task.
- **Sam** drafted the one-page plan.
- **Robin** reviewed it and caught what was missing.
- `/vcos-session-close` captured the decisions and lessons into the cognitive layer.

What's in here:

- `docs/project_context.md` — the filled-in context (what this is, the goal, the constraints).
- `project cognitive layer/STANCE.md` — the decision log with real entries.
- `project cognitive layer/MINDSET.md` — the distilled principles that came out of it.
- `sample-output.md` — an example of what Sam actually produced.

Read them top to bottom to see how a session flows from a vague idea to captured judgment.
