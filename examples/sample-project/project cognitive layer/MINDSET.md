# MINDSET — Weekend Trip Plan

> Read-only example. These principles were distilled from the SIGNALS this project produced — this is what "earned judgment" looks like after one project.

Distilled lessons from this project. Generated from project SIGNALS at the end of the project.

---

## Decision Heuristics
- Start with the smallest useful version. A one-page, one-weekend plan beats a grand itinerary you never finish.
- Define "done" in one sentence before making anything, so the maker and the reviewer aim at the same target.

## What Worked
- One anchor activity per day kept the plan feeling relaxing instead of packed.
- A soft budget cap with a buffer was easier to live with than a hard limit, and still kept spending bounded.

## Risk Profile
- The real risk wasn't the big choices; it was the small omissions. A quick "what if it rains / it's closed / we're late?" pass caught the day-ruining gaps cheaply.

## Anti-Patterns
- Trusting the first draft's budget. The unglamorous costs (travel, parking) get dropped first and need to be checked back in.
- Over-scheduling. Three activities a day turns a break into a chore.

## Open Promotions → Global MINDSET
- "First drafts drop the boring line items — check for omissions" looks general. If it shows up in another project, it's a candidate to promote to the global layer.
