for this project. This feeds project SIGNALS.

Updated: Any persona after a meaningful cross-cutting decision

## Rules
- Append only — do not edit or delete past entries
- Each entry ≤3 lines, one idea per entry
- Tag the source: [self] or [persona-name]
- Mark [Recurring] if a pattern appears ≥2 times → eligible for SIGNALS

## Entry Types
- [Decision] → what was chosen and why
- [Heuristic] → a working rule used in this project
- [Constraint] → limitation affecting decisions
- [Mistake] → what went wrong and correction
- [Conflict] → persona disagreement and how it was resolved
- [Preference] → observed behavioral tendency
