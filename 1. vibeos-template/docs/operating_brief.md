# OPERATING_BRIEF

The planning artifact for **non-software work** — decisions, plans, process changes, analyses,
and strategy. The counterpart to the Build Packet: where a Build Packet specs something you
build, an Operating Brief frames a decision and how it lands. Use this when the deliverable is
a decision, a framework, an analysis, or a change in how things are done — not a tool.

(If this project builds software, use `build_packet.md` instead.)
